Coverage uses 28 summary features: signed servo-error mean and standard deviation, velocity mean/RMS, command-change RMS, nominal source unsaturated fraction and near-clipping fraction, each on four ankles. Servo error uses state[i] with action[i+1]. This is a transparent heuristic for command-state diversity; it is not guaranteed to optimize neural-model information or downstream control.

It does not pool deployment trials from two policies into192 independent training observations, estimate population uncertainty from two training seeds, or use a composite score to declare a winner. Repeat inputs and copied floor diagnostics are checked against the primary files and recorded hashes.

Completion and mean survival include all96 deployment trials. Prefix errors condition on completing that prefix; full-reference errors condition on full completion, with the counts displayed.
