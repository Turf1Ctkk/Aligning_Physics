# Passive two-gain identification: measured results

This is SPI-style parameter fitting in the common G1 framework, not full SPI-Active. Eight CMA-ES generations of 12 candidates fit separate ankle pitch/roll gains from the mixed30 pool. Each candidate uses one central window per continuous training segment, task/group/segment weights, and a fixed first-0.25-second joint-position/velocity loss. No target gain labels enter fitting. [Search history](history.json) and [identified parameters](identified.json) record 96 candidate evaluations.

The selected pitch and roll gains are **13.0122 and 10.4212**, whereas the configured target values are both 16. These parameters are fitted from trajectory error and are not validated physical parameter recovery. A completed [post-hoc known-gain check](posthoc_diagnostic.json) reuses the same 41 central training windows and fitting loss: source20 scores 1.11580, known16 scores 0.48918, and fitted gains score0.27028. The current objective prefers the fitted surrogate even to the true parameters. Thus finite search alone does not explain the failure to recover gains; short-horizon objective bias and incomplete initialization remain plausible, unproven explanations. Known16 enters this diagnostic only, not fitting or active-design selection.

On the isolated 66-window test, one-second body MPJPE is **30.87 mm**, ankle RMSE **0.05287 rad**, and joint-velocity RMSE **0.80029 rad/s**. Relative to source Kp20 replay, body and velocity errors decrease from 37.66 mm and 0.87892 rad/s. All windows complete. [Raw held-out summaries](replay_comparison.json) also show validation and per-task outcomes.

After 1000 additional Squat policy updates in the fitted simulator, standalone B deployment completes **93/96 trials** versus **96/96** for fine-tuning in the original source simulator. First-second global error is lower, but root-relative error and completion are worse. [Matched downstream comparison](../matched_squat/README.md). This estimator uses a subset and a different calibration objective from action-residual training; it is not a matched-data ranking of model representations.
